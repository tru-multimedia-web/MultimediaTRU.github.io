🎬 คู่มือการฝังวิดีโอจาก Google Drive

เอกสารนี้อธิบายขั้นตอนการแชร์วิดีโอจาก Google Drive เพื่อนำมาใช้บนเว็บไซต์อย่างถูกต้อง

ขั้นตอนที่ 1: อัปโหลดวิดีโอไปยัง Google Drive

1.1 เข้าสู่ระบบ Google Drive ของคุณ

1.2 อัปโหลดไฟล์วิดีโอที่คุณต้องการใช้งาน

ขั้นตอนที่ 2: ตั้งค่าการแชร์ (สำคัญที่สุด)

2.1 คลิกขวาที่ไฟล์วิดีโอที่อัปโหลดแล้วเลือก "แชร์" (Share)

2.2 ในหน้าต่างที่ปรากฏขึ้น, ที่ส่วน "การเข้าถึงทั่วไป" (General access), เปลี่ยนจาก "จำกัด" (Restricted) เป็น "ทุกคนที่มีลิงก์" (Anyone with the link)

2.3 ตรวจสอบให้แน่ใจว่าสิทธิ์ที่กำหนดคือ "ผู้มีสิทธิ์ดู" (Viewer)

2.4 คลิก "คัดลอกลิงก์" (Copy link) แล้วกด "เสร็จสิ้น" (Done)

ข้อควรระวัง

หากไม่ตั้งค่าการแชร์เป็น "ทุกคนที่มีลิงก์" วิดีโอจะไม่สามารถแสดงผลบนเว็บไซต์ได้ และผู้ใช้ทั่วไปจะมองไม่เห็นวิดีโอของคุณ

ขั้นตอนที่ 3: คัดลอก File ID

3.1 ลิงก์ที่คุณคัดลอกมาจะมีลักษณะดังนี้:

https://drive.google.com/file/d/FILE_ID/view?usp=sharing

3.2 ส่วนที่เราต้องการคือ FILE_ID ซึ่งเป็นรหัสเฉพาะของไฟล์วิดีโอของคุณ

ตัวอย่าง: จากลิงก์ https://drive.google.com/file/d/1aBcDeFgHiJkLmNoPqRsTuVwXyZ_12345/view?usp=sharing

FILE_ID คือ: 1aBcDeFgHiJkLmNoPqRsTuVwXyZ_12345

ขั้นตอนที่ 4: สร้างโค้ดสำหรับฝัง (Embed Code)

4.1 นำ FILE_ID ที่ได้มาไปใส่ใน URL รูปแบบพิเศษสำหรับการฝังวิดีโอ:

https://drive.google.com/file/d/YOUR_FILE_ID/preview

4.2 นำ URL ที่ได้ไปใส่ใน thuộc tính src ของ <iframe> ในไฟล์ index.html

ตัวอย่างโค้ด iframe:

<iframe 
    src="https://drive.google.com/file/d/1aBcDeFgHiJkLmNoPqRsTuVwXyZ_12345/preview" 
    frameborder="0" 
    allow="accelerometer; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" 
    allowfullscreen
    loading="lazy"
    width="100%"
    height="315"
    title="ชื่อวิดีโอของคุณ">
</iframe>

สรุป

1. อัปโหลดวิดีโอ ไปยัง Google Drive

2. ตั้งค่าการแชร์ เป็น "ทุกคนที่มีลิงก์" (Anyone with the link)

3. คัดลอก File ID จากลิงก์ที่แชร์

4. สร้าง URL สำหรับฝัง โดยใช้รูปแบบ /preview

5. นำไปใส่ใน iframe ของเว็บไซต์
