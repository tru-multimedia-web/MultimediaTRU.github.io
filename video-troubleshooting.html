🔧 คู่มือแก้ไขปัญหาวิดีโอ YouTube

สาขาเทคโนโลยีมัลติมีเดีย มหาวิทยาลัยราชภัฏเทพสตรี

🚀 ลิงค์ด่วน

🏠 หน้าหลัก 🔧 Admin Panel 🧪 ทดสอบวิดีโอ

🎯 ปัญหาที่พบบ่อย

1. วิดีโอที่เพิ่มใน Admin Panel ไม่แสดงในหน้าหลัก

1 ตรวจสอบว่าได้บันทึกวิดีโอแล้ว: กดปุ่ม "เพิ่มวิดีโอ" ใน Admin Panel และดูว่ามีข้อความ "เพิ่มวิดีโอสำเร็จ" หรือไม่
2 รีเฟรชหน้าเว็บ: กด F5 หรือรีเฟรชหน้าเว็บหลัก
3 กดปุ่ม "รีเฟรชแกลเลอรี่": ในหน้าหลัก หาปุ่ม 🔄 รีเฟรชแกลเลอรี่ และคลิก
4 ตรวจสอบ Console: กด F12 เปิด Developer Tools แล้วดูข้อความใน Console tab

2. วิดีโอแสดงเป็นกรอบเปล่า

1 ตรวจสอบลิงค์ YouTube: ให้แน่ใจว่าลิงค์ YouTube ถูกต้องและเปิดได้
2 ตรวจสอบ Video ID: ตรวจสอบว่า Video ID ยาว 11 ตัวอักษรและไม่มีตัวอักษรพิเศษ
3 ลองวิดีโอใหม่: ทดสอบด้วยวิดีโอ YouTube อื่นที่แน่ใจว่าใช้งานได้

3. Admin Panel ไม่ทำงาน

1 ตรวจสอบ Browser: ใช้ Chrome, Firefox, หรือ Safari เวอร์ชันใหม่
2 เคลียร์ Cache: กด Ctrl+Shift+R (Windows) หรือ Cmd+Shift+R (Mac)
3 ตรวจสอบ JavaScript: ให้แน่ใจว่า JavaScript ไม่ถูกบล็อค

🛠️ เครื่องมือแก้ไขปัญหา

การใช้ Console Commands

เปิด Developer Tools (F12) และพิมพ์คำสั่งเหล่านี้ใน Console:

// ตรวจสอบสถานะระบบ debugVideoGallery() // บังคับโหลดวิดีโอใหม่ forceReloadVideos() // ตรวจสอบปัญหา checkVideoLoadingIssues() // ดูสถานะ Video Gallery Manager getVideoGalleryStatus()

การแก้ไขปัญหาด้วย Video Test Page

1 เปิด หน้าทดสอบวิดีโอ
2 คลิก "ตรวจสอบ Storage" เพื่อดูข้อมูลที่บันทึกไว้
3 คลิก "เพิ่มวิดีโอทดสอบ" เพื่อทดสอบการทำงาน
4 คลิก "โหลดจาก Storage" เพื่อดูผลลัพธ์

📋 ขั้นตอนการแก้ไขปัญหาทีละขั้น

⚠️ ข้อควรระวัง: ก่อนเริ่มแก้ไขปัญหา ให้สำรองข้อมูลวิดีโอที่มีอยู่เสียก่อน

ขั้นตอนที่ 1: การตรวจสอบเบื้องต้น

  1. เปิด Admin Panel และตรวจสอบว่ามีวิดีโอที่ต้องการหรือไม่
  2. ลองเพิ่มวิดีโอใหม่และดูว่ามีข้อความสำเร็จหรือไม่
  3. รีเฟรชหน้าเว็บหลักและดูผลลัพธ์
  4. หากยังไม่แสดง ไปขั้นตอนที่ 2

ขั้นตอนที่ 2: การตรวจสอบระบบ

  1. เปิด Developer Tools (กด F12)
  2. ไปที่ Console tab
  3. พิมพ์ debugVideoGallery() และกด Enter
  4. ดูข้อความที่แสดงออกมา

ขั้นตอนที่ 3: การแก้ไขปัญหา

A หากไม่พบข้อมูลใน Storage:
  • กลับไป Admin Panel และเพิ่มวิดีโอใหม่
  • ตรวจสอบว่ากดปุ่ม "เพิ่มวิดีโอ" แล้ว
  • ดูข้อความยืนยันการบันทึก
B หากพบข้อมูลแต่วิดีโอไม่แสดง:
  • พิมพ์ forceReloadVideos() ใน Console
  • รอสักครู่และดูผลลัพธ์
  • หากยังไม่ได้ผล ลองรีเฟรชหน้าเว็บ
C หากวิดีโอแสดงแต่เป็นกรอบเปล่า:
  • ตรวจสอบลิงค์ YouTube ใน Admin Panel
  • ลองคัดลอกลิงค์ไปเปิดใน Browser ใหม่
  • หากเปิดไม่ได้ ให้เปลี่ยนเป็นวิดีโออื่น

ขั้นตอนที่ 4: การรีเซ็ตระบบ (กรณีฉุกเฉิน)

⚠️ คำเตือน: การดำเนินการนี้จะลบวิดีโอทั้งหมดใน Admin Panel
  1. เปิด Console (F12)
  2. พิมพ์ localStorage.clear()
  3. รีเฟรชหน้าเว็บ
  4. เพิ่มวิดีโอใหม่ใน Admin Panel

✅ การตรวจสอบว่าแก้ไขปัญหาสำเร็จ

ระบบทำงานปกติเมื่อ:

  • ✅ วิดีโอที่เพิ่มใน Admin Panel แสดงในหน้าหลัก
  • ✅ วิดีโอโหลดได้ (ไม่ใช่กรอบเปล่า)
  • ✅ ระบบกรองหมวดหมู่ทำงาน
  • ✅ การอัปเดตวิดีโอทำงานแบบเรียลไทม์
