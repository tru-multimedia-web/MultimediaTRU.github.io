# 🎬 คู่มือการใช้งาน Admin Panel - Video Gallery Management

## 📋 ภาพรวมระบบ

ระบบ Admin Panel นี้ช่วยให้ผู้ดูแลระบบสามารถจัดการคลังวิดีโอผลงานนักศึกษาได้โดยไม่ต้องเขียนโค้ด HTML

## 🚀 วิธีการใช้งาน

### 1. เปิดหน้า Admin Panel
- เปิดไฟล์ `admin.html` ในเบราว์เซอร์
- หน้าจอจะแสดง Admin Panel พร้อมฟอร์มสำหรับจัดการวิดีโอ

### 2. เพิ่มวิดีโอใหม่
1. **YouTube URL**: วาง URL ของวิดีโอ YouTube 
   - รูปแบบที่รองรับ: `https://www.youtube.com/watch?v=VIDEO_ID`
   - หรือ: `https://youtu.be/VIDEO_ID`

2. **หมวดหมู่**: เลือกหมวดหมู่ที่เหมาะสม
   - แอนิเมชัน
   - เกม
   - เว็บไซต์
   - วิดีโอ
   - กราฟิก

3. **ชื่อโครงการ**: ใส่ชื่อของผลงาน
   - ตัวอย่าง: `แอนิเมชัน 2D "เรื่องเล่าจากอดีต"`

4. **ชื่อนักศึกษา**: ใส่ชื่อผู้สร้างผลงาน
   - ตัวอย่าง: `น.ส. สมใจ ใจดี`

5. **รายละเอียดโครงการ**: อธิบายผลงานโดยสังเขป

6. กด **"บันทึกวิดีโอ"**

### 3. จัดการวิดีโอ
- **แก้ไข**: กดปุ่ม "แก้ไข" เพื่อโหลดข้อมูลเก่ามาในฟอร์ม
- **ลบ**: กดปุ่ม "ลบ" เพื่อลบวิดีโอออกจากระบบ

### 4. สร้างโค้ด HTML
1. เมื่อเพิ่มวิดีโอครบแล้ว กดปุ่ม **"สร้างโค้ด HTML อัพเดท"**
2. ระบบจะสร้างโค้ด HTML ใหม่ที่มีวิดีโอทั้งหมด
3. กดปุ่ม **"คัดลอกโค้ด"** เพื่อคัดลอกโค้ด
4. ไปที่ไฟล์ `index.html`
5. หาส่วน `<!-- Video Gallery Section -->` และแทนที่ด้วยโค้ดใหม่
6. บันทึกไฟล์

## 💾 การเก็บข้อมูล

- ข้อมูลวิดีโอจะถูกเก็บใน Browser's localStorage
- ข้อมูลจะไม่หายไปเมื่อปิดเบราว์เซอร์
- หากต้องการล้างข้อมูลทั้งหมด ให้ล้าง localStorage ของเบราว์เซอร์

## 🔧 คุณสมบัติเพิ่มเติม

### ✅ การตรวจสอบ URL
- ระบบจะตรวจสอบว่า URL เป็น YouTube URL ที่ถูกต้อง
- แจ้งเตือนหาก URL ไม่ถูกต้อง

### 🎯 การตรวจสอบซ้ำ
- ไม่อนุญาตให้เพิ่มวิดีโอที่มี URL เดียวกันซ้ำ

### 📱 Responsive Design
- ใช้งานได้บนมือถือและแท็บเล็ต

### 🎨 Preview Thumbnail
- แสดงรูปย่อของวิดีโอจาก YouTube

## 🚨 ข้อควรระวัง

1. **URL YouTube เท่านั้น**: ระบบรองรับเฉพาะ YouTube
2. **การสำรองข้อมูล**: ควรสร้างโค้ด HTML สำรองเป็นระยะ
3. **การอัพเดทเว็บไซต์**: ต้องคัดลอกโค้ดใหม่ไปแทนที่ในไฟล์ index.html ทุกครั้ง

## 📞 การติดต่อสนับสนุน

หากมีปัญหาในการใช้งาน:
1. ตรวจสอบ Console ของเบราว์เซอร์ (F12)
2. ลองรีเฟรชหน้าเว็บ
3. ตรวจสอบว่า JavaScript เปิดใช้งาน
