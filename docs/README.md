## 🏗️ โครงสร้างโปรเจค

```

├── server/                 # ไฟล์เซิร์ฟเวอร์
├── scripts/               # สคริปต์จัดการเซิร์ฟเวอร์
├── css/                   # ไฟล์สไตล์ชีต
├── js/                    # ไฟล์ JavaScript
├── images/                # รูปภาพและไฟล์สื่อ

├── docs/                  # เอกสารประกอบ (ไฟล์นี้)

├── video-generator.html  # เครื่องมือจัดการวิดีโอ
├── player.html           # หน้าเล่นวิดีโอ
├── package.json          # Dependencies
└── README.md             # ไฟล์หลัก
```
